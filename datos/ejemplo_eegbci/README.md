# EEG público de ejemplo

`S001R01.edf` pertenece al sujeto 1, corrida 1, del **EEG Motor Movement/Imagery Dataset v1.0.0**. Es una grabación basal de un minuto con ojos abiertos, 64 canales EEG, frecuencia de muestreo de 160 Hz y formato EDF+.
